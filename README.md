# My portfolio
Welcome to my portfolio! I started this project to help me represent myself and to keep my projects at one place for anyone to see :)

## About the design:
- Initially, I started by creating something using the Neo-Brutalism style, like the buttons, then I evolved to something more colorful.
- Fonts used: `Rubik` and `Holtwood One SC`.
- Customizable user experience, allowing users to change the site's main colors.

There's also a button to switch between light and dark themes.

I hope you like it!
